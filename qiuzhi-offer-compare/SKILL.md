# 多 Offer 对比决策

在多个机会之间做决策，核心产出是"放弃阈值"和"长期路径判断"。写入 `企业对比.md`。

## 输入

- 各企业分析文档 + 已获 offer 细节（薪资/福利/试用期/年终/年假）+ 候选人职业目标

## 处理流程

### 1. Offer 概况表

岗位/公司属性/薪资/福利/工作内容/稳定性/稀缺性/目标城市编制，一表并列。

### 2. 收入测算（关键：福利折算）

- 底薪 → 到手（扣社保公积金）→ 年综合（含公司公积金 + 年终奖）
- **隐性福利差折算成每年损失金额**：公积金比例差（如 5% vs 12%）、社保基数差、试用期打折、年假缩水
- 结论要落到"哪家底薪与哪家相当"的具体数字

### 3. 多维度对比

确定性 / 稳定性 / 工作内容关联 / AI 含量 / 转型价值 / 人脉 / 环境 / 风险。

### 4. 决策条件表（放弃阈值）

> **铁律：放弃一个已落袋的稳定 offer，对方必须同时满足"薪资不输 + 稳定性不差 + 价值（福利/内容/赛道）明显更高"。三条缺一不换。**

- 央企编制：底薪同等即算赢（福利碾压），不必要求高于现状
- 小公司转型岗：需超额溢价（如高出 3K+）才考虑对冲风险
- 每种情形给明确决策，不模棱两可

### 5. 长期路径对比（第一决策标准）

> **"这岗位 5-10 年后能不能让我持续坐在'定义问题'的位置？"**

- 两条出路：A. 强者开发者 → 组小团队出品产品；B. 在大企业抢占高生态位。共同前提是始终在"定义问题"一侧
- 判断维度：位置来源（组织给=被动 / 自己挣=主动 / 关系给=最不稳）、岗位边界清晰度、位置可携带性、期权可能、主动权
- 结论：成长期公司岗位边界模糊 = 主动权在自己手里，最优；成熟大厂岗位边界清晰 = 需主动突破才避免成为被动执行者

## 输出

`企业对比.md`（追加新企业分析 + 更新决策）。结构：三个 Offer 概况 → 收入测算 → 多维度对比 → 核心决策逻辑 → 决策条件表 → 最终建议。

## 注意事项

- 结论必须可执行：每个情形对应一个明确动作（签 / 换 / 等 / 谈）
- 别被"赛道热度"绑架：信心建立在已到手的价值，而不是新赛道的想象
