# 企业独立分析

对一家企业做"这家值不值得"的独立判断。产出固定结构文档，结论先行。

## 输入

- 企业名称 / JD 文本 / 面试邀约
- 候选人的硬约束（目标城市、排除外包、职业转型方向）从 qiuzhi-flow 继承

## 处理流程

### 1. 搜集基本面（WebSearch / 公开资料）

- 股权结构（央企/民企/外企/上市公司/子公司）、注册资本、融资轮次、估值
- 规模（人数/参保）、成立时间、办公地
- 产品与技术方向、行业排名/市场份额
- 目标城市布局（**城市约束是硬前提**，无目标城市办公点直接排除或标注待确认）

### 2. 解析 JD 真实画像

- 岗位职责逐条拆解，提炼"这岗位到底解决什么问题"
- 区分"JD 写的" vs "面试才知道的"。**教训：JD 写解决方案岗，实际可能是运维分析岗——务必提示候选人在面试首轮确认真实画像**

### 3. 匹配度评估表（五维评分 1-5）

| 维度 | 打分依据 |
|------|---------|
| 技术契合 | 岗位所需能力 vs 候选人技术栈重合度 |
| 公司实力 | 融资/规模/产品/排名 |
| 赛道热度 | 岗位所属方向的市场热度 |
| 目标城市落地 | 是否有目标城市编制/办公点 |
| 转型契合 | 是否符合职业转型诉求（转管理/产品/AI） |

### 4. 结论先行

综合评分 + 一句话判断（强烈建议 / 有条件试 / 不推荐）。

## 输出

`{企业}分析.md`，固定结构：

1. 结论先行（一句话 + 综合评分）
2. 公司情况（能从公开信息确认的基本面）
3. 岗位理解（岗位到底做什么、行业定位、为什么热/不热）
4. 与候选人匹配度评估（强匹配项 / 需诚实面对的短板 / 方向权衡）
5. 匹配度评分表
6. 薪资/福利预期参考（作为后续谈薪锚点，标注"需面试确认"）
7. 给候选人的行动建议（含待确认清单：工作地/编制/团队构成/考核导向）
8. 信息源

同步把企业名称和简介登记到 `相关企业.md`（含排除/高优先级分类）。

## 注意事项

- 关键前提（如"目标城市是否有研发编制"）必须列为行动建议第一项，不要假设
- 企业分析文档与全局对比文档分离：本技能只管"这家值不值得"，多家怎么选交给 qiuzhi-offer-compare
