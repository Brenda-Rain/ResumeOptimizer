# 面试准备

为单个岗位生成可执行的面试准备材料，写入 `面试细节.md` 的岗位专项章节。

## 输入

- 企业分析文档 + JD + 已知的面试轮次安排 + 候选人的职业方向/素材

## 处理流程

### 1. 岗位理解

一句话讲清"这岗位解决什么问题"（30 秒能脱口而出）。

### 2. 面试定位

按岗位性质决定"突出什么、隐藏什么"：

- 纯研发岗：**不谈想转产品/管理**（说了减分），突出技术功底 + 领域理解
- 软实力面/技术产品向：突出 AI 落地 + 表达 + 判断力
- 通用：稳定性信号（本地人回流定居）照常使用

### 3. 技术准备

- 必背核心概念（能脱稿讲）
- 工具链生态横向对比（展示认知深度）
- **代码准备**（提示候选人大概率手写代码的岗位）：必刷经典题（如 ReAct loop、工具调度器、状态机、Min Stack）；明确告知"团队考代码就要刷经典题"
- 每个重点题给出"回答框架"（业务约束 → 方案对比 → 推荐方案 → 工程细节 → 收尾金句），而不是干巴巴的答案

### 4. 关键预判问答表

Q（你凭什么胜任/你的短板/高频动机题）+ 参考思路。覆盖：为什么离开上家、为什么转型、为什么选中小企业、为什么选城市、薪资期望、最大缺点、AI 经验。

### 5. 反问清单

挑 2-3 个体现思考深度的问题，优先"工作地/编制/团队构成/考核导向/晋升通道"。

### 6. 主线速记

把散落知识压缩成一页"面试主线速记"（三句话框架：岗位理解 + AI 翻译 + 防御话术），面试前一小时只看这一页。

## 分轮应对（职级逐级上升规律）

| 轮次 | 面试官 | 关注 | 给足 | 克制 |
|------|--------|------|------|------|
| 1 | 小组 Leader | 能不能干活 | 项目细节/量化 | 别甩大局观 |
| 2 | 部门主管 | 能不能扛目标 | 业务方案/跨团队 | 别抠技术实现 |
| 3 | 部门经理 | 够不够格局 | 判断力/视野/潜力 | 别讲具体代码 |
| 4 | HR | 稳不稳 | 稳定性/动机 | 别太迫切 |

## 输出

`面试细节.md` 中新增该岗位的专项章节，结构：岗位理解 → 关键话术调整 → 重点展示匹配点 → 技术准备 → 预判问题 → 反问清单 → 重点题参考答案 → 主线速记。
